# portfolio

My personal development portfolio — an on-scroll, animated site built with
Next.js, TypeScript, Tailwind CSS, and GSAP, focused on AI engineering,
product building, and software engineering work.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

See `CLAUDE.md` for the tech stack, project structure, and content model.
